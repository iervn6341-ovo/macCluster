# 文件去識別化與發布檢查

2026-10-20 已檢查專案文件、Skill、範例與可提交的文字檔案，包含尚未加入 Git 的檔案。

## 使用的示範值

- 節點：`maccluster-node`；Pod 隨機後綴使用 `<replicaset>-<suffix>`。
- 位址：使用文件保留網段 `192.0.2.0/24`、`198.51.100.0/24`、`203.0.113.0/24`。
- 路徑：使用 `$HOME`、`/path/to/...`、`/Volumes/...` 或明確佔位值。
- 憑證：不保存真實 token、私鑰或完整 kubeconfig；範例以 `TOKEN`／`HASH` 等佔位值表示。
- 網路設計文件中的位址已替換，不能直接視為實際環境設定。

程式的通用預設網段不是部署紀錄。檢查腳本僅對出站代理實作及其說明中的兩個完整預設 CIDR 做精確豁免，不豁免整份檔案。

## 檢查方式

```bash
./scripts/check-privacy.sh
```

檢查 Git 已追蹤及未追蹤、未被忽略的文字檔案，包含隱藏的 Skill 目錄；檔名含空白也會正確處理。失敗時只列檔名、行號與類型，不印出命中的敏感值。

`.local/`、`.tools/`、`dist/`、建置快取與獨立的設計參考專案不在掃描範圍；本機連線設定與執行狀態沒有因此被修改。不要以 `git add -f` 將這些資料加入版本控制。

## 圖片與範圍

README 的 `images/maccluster-overview.png` 經視覺檢查後，使用者明確選擇保留原始畫面。因此圖片仍包含當時的內網位址、節點與服務名稱，**不屬於已去識別化的素材**。文字掃描不會進行 OCR，也不檢查二進位檔案的中繼資料。

本次檢查針對目前工作目錄，不代表已改寫 Git 歷史、既有遠端提交、Actions artifacts 或其他已發布的副本。正式發布前應再次執行檢查，並確認即將提交的差異與圖片。
